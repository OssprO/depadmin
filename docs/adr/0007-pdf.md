# ADR-0007: PDF con @react-pdf/renderer

**Estado:** Aceptado · **Fecha:** 2026-10-07

## Contexto

El reporte mensual se descarga y se comparte en PDF (spec §5). El VPS tiene recursos limitados.

## Decisión

@react-pdf/renderer, que se ejecuta en el backend, como adaptador de salida del módulo `reports`.

## Consecuencias

- No hace falta Chromium: la imagen es ligera y usa poca RAM. Puppeteer se descartó porque cuesta unos 300 MB más por contenedor.
- El diseño se escribe con componentes React y su propio sistema de estilos (no Tailwind).
- El PDF de un mes cerrado se genera desde su snapshot, así que siempre sale idéntico.
